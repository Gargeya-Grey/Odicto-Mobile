# Odicto Mobile verification map

Read the entry matching the changed user journey. Every journey requires the device and candidate-build preconditions in [the skill](../SKILL.md). These recipes are unproven until run on a real target; missing preconditions are NOT CHECKED, not passes.

- [Settings and providers](settings-providers.md) covers independent AI Answers and Text Polish provider selection and persistence.
- [Text Polish](text-polish.md) covers selected and whole-field correction, recovery, and provider failures.
- [Keyboard and protected fields](keyboard.md) covers visible typing, emoji, and protected-field refusal.
- [Voice dictation](voice.md) covers Raw, AI, and Live through the keyboard and optional floating microphone.
